## Module navigation

1. Contracts — contract repository and lifecycle.
2. Procurement — plans, requisitions and line items.
3. Vendors — evaluation and selection.
4. Invoices & Payments — invoice review and payment records.

The companion workbook is required before assigning these areas to later sprints or displaying story IDs. Role labels come only from the project brief.
