# Sprint 0 Scope Notes

Scope is taken from the J14 master brief: repository setup, Oracle design, initial wireframes, backend and Angular skeletons, and login. The named project roles are Safety Officer and Contracts Manager.

The companion workbook containing official epics, user stories, role permissions and Sprint 1–3 allocations was not supplied. All vendor, user, contract, invoice and payment sample records are invented for training. No classified or operational defence information is included.
